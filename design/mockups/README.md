## Shared visual contract

- Deep burgundy venue context and navigation
- Warm blush operational canvas
- Crays pink for current location and primary actions
- Coral for attention and service handoffs
- Semantic mint, amber, red, and blue only where status requires them
- Flat, bordered working surfaces with 48 dp touch targets
- Persistent tablet rail; compact venue header and five-item bottom navigation on phones
- No Nuts Cash emerald styling, generic SaaS metric grid, glass effects, or desktop-only interaction
